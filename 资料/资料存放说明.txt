把要放进资源中心的资料（PDF / Word / 图片 / 视频 / 链接等）放到这个「资料」文件夹里。
**重要：文件名只用英文/数字/短横线（如 org-intro-v149.pdf），不要用中文名**——中文名在 Web 服务下浏览器容易 404。

添加一条资料的步骤（由我操作，你只需把文件丢进来并告诉我）：
1. 把文件放进本文件夹，例如 研究院介绍_官网简介.pdf
2. 我会在 data.json 对应分类下加一条：
   { "title":"官网简介", "type":"doc", "permission":"view", "file":"资料/研究院介绍_官网简介.pdf", "desc":"机构官网简介" }
   - permission 填 "download" = 可下载，填 "view" = 仅查看
   - type 填 doc / video / image / link / other
3. 重新发布，线上即更新。
